# Glitch-Runner-2D
A 2D glitch-themed endless runner built in Godot 4.7

## About

You jump over obstacles to survive. Activate the glitch power-up to pass through obstacles. You face gravity flips and speed surges.

## Play

- **Web**: [Play on itch.io](https://kaazmo.itch.io/glitchrunner2d)

## Controls

- **SPACE** - Jump
- **SHIFT** - Glitch or phase through objects
- **ESC** - Pause
- **M** - Mute SFX
- **P** - Mute Music

## Features

- 3 playable characters
- Scott
- Cynthia
- Rocket
- Difficulty scaling
- Glitch mechanics
- Score tracking

Made with Godot 4.7.2
